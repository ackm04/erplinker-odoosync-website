Requirements

OdooSync system requirements

  • WordPress 5.8 or newer
  • WooCommerce 6.0 or newer
  • PHP 8.0 or newer
  • Odoo 18 or 19 (Community or Enterprise)
  • Odoo XML-RPC enabled on your instance

No custom Odoo module is required — OdooSync uses Odoo's standard XML-RPC API.

Quick start with Lite

  1. Clone or download from GitHub
  2. Upload to wp-content/plugins/
  3. Activate in WordPress
  4. Open OdooSync Lite → Settings
  5. Enter Odoo URL, database, and credentials
  6. Test connection, enable sync, save

FAQ

WooCommerce Odoo sync FAQ

Can Lite and Pro run together?

No. They share core class names. Lite detects Pro and stays inactive so you can safely remove Lite after upgrading.

Which Odoo versions are supported?

Odoo 18 and Odoo 19, both Community and Enterprise editions.

Is WooCommerce HPOS supported?

Yes. Both editions declare HPOS compatibility and use WooCommerce CRUD APIs for order data.

How are credentials stored?

Credentials are encrypted at rest. Pro adds PBKDF2 key derivation with per-credential salts and independent security auditing.

Where do I get Pro?

Pro is available from ERP Linker. Lite remains free and open source on GitHub.

Does OdooSync require a custom Odoo module?

No. OdooSync uses Odoo's standard XML-RPC API. No custom Odoo module or server-side changes are required.
